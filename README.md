\# Customer Churn Prediction



A machine learning project that predicts whether a telecom customer is likely to leave the service.



\## Features

\- Data preprocessing using scikit-learn pipelines

\- Logistic Regression and Random Forest models

\- Churn prediction through a Streamlit web app

\- Risk classification using a 0.40 probability threshold



\## Technologies Used

\- Python

\- Pandas

\- Scikit-learn

\- Streamlit

\- Joblib



\## Run Locally

Install dependencies:



```bash

pip install -r requirements.txt

```



Start the app:



```bash

python -m streamlit run app.py

```
